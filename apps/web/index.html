GC shape stenciling in Go generics

Generic functions in Go don't get a fresh compiled body for every type you plug in. The compiler buckets types by their "GC shape" — how the garbage collector needs to see them in memory — and lets every type in a bucket share one function body, resolving the type-specific bits through a dictionary passed in at the call site. This piece walks through why that tradeoff exists, what a GC shape actually groups together, and where the dictionary lookups show up if you go looking for them.
